Add the runtime dependencies of server to your project:
  uv add "fastapi>=0.141.1" "pydantic>=2.14.0" "typing-extensions>=4.16"
Next steps: implement service/services/pets.py (created), service/services/store.py (created), then run the server:
  uv add uvicorn && uv run uvicorn server.main:app --reload
or `fastapi dev service/server/main.py` with "fastapi[standard]"; see service/server/README.md.
